# My Personal Static Website

I'd admit that this the webpage is not written solely on my own, but using a template generated by AI.

## Note
Do not directly clone and deploy the page without modification. Both your cloned webpage and my backend will explode if you do that.

## Structure report

This page is hosted on github.io, a convenient and free static webpage hosting service. To apply dynamic data, you have two approaches:

1. Do a `git push` everytime you want to update the contents;
2. Implement an external backend.

Here is how my thing works, and that's why I said do not clone and implement directly:
```
    Client device     <-    github.io           <->    Private external backend
    (Your browser)          (Static HTML, JS)          (Game stats, Now playing)
```

The external backend is hosted privately and close-sourced for security reasons. Of course you can implement your own version.

### Now-Playing
This is scrapped from the listening history of YTMusic using [mysterious approach](https://github.com/sigma67/ytmusicapi). You may implement a spotify version yourself as its API is public.  

### ZZZ Stats
This is scrapped from the HOYOLAB server using [mysterious approach](https://github.com/seriaati/genshin.py).

### Arknights, NTE, maimai, CHUNITHM
The games mentioned above, sadly, doesn't provide a feasible solution to dynamically update the game stats. The static identity photo is stored directly in this site.
